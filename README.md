# 小账本

一款隐私优先的个人记账程序。账目保存在当前浏览器的本地存储中，不需要账号；还可使用智谱免费的 `glm-4.7-flash` 模型，把一句自然语言自动整理成收支类型、金额、分类、账户和日期，确认后记账。

## 使用方法

首次使用需要安装 Node.js 22 或更高版本，然后在项目目录运行：

```powershell
npm install
npm run dev
```

开发时浏览器打开 `http://localhost:3000`。日常使用直接双击桌面上的“小账本”快捷方式：隐藏启动器会拉起一个极轻的本地服务，并由系统默认浏览器打开 `http://localhost:32145`；关闭页面后服务会自动退出。

小账本不会注册开机启动项。只有双击快捷方式后才会运行；关闭最后一个小账本页面后，本地服务会在约 4 秒内退出。

## 配置 AI 智能记账

1. 在[智谱开放平台](https://open.bigmodel.cn/usercenter/apikeys)创建 API Key。
2. 复制项目根目录的 `.env.example` 并重命名为 `.dev.vars`。
3. 将 `.dev.vars` 中的 `your_zhipu_api_key` 替换成自己的 Key，然后重新启动程序。

```dotenv
ZHIPU_API_KEY=你的智谱API_Key
```

真实 Key 只保存在本机的 `.dev.vars`，该文件已被 Git 忽略，不会提交到 GitHub；桌面启动器也兼容已有的 `.env.local`。部署到服务器时，请在部署平台中把 `ZHIPU_API_KEY` 配置为服务端密钥，不要写入前端代码或仓库。若站点对外公开，还应先增加登录与调用限流，避免他人消耗你的接口额度。

打开程序后点击右上角“AI 记账”，可以输入：

> 今天在学校食堂吃午饭，微信付了 18.5 元

AI 会自动填写“支出 / 18.50 元 / 餐饮 / 微信钱包 / 今天”，你可以检查和修改后再确认保存。调用使用智谱官方聊天补全接口与 `glm-4.7-flash` 模型；官方当前将该模型标注为免费模型，具体额度和政策以[模型文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)与[价格页](https://bigmodel.cn/pricing)为准。

## 已有功能

- 记录收入和支出，支持编辑、删除、搜索和筛选
- AI 自然语言记账，自动识别收支、金额、分类、账户与日期
- 现金、银行卡、电子钱包等多账户余额
- 月度预算、近七日趋势、支出分类排行和月度结余
- JSON 数据备份与恢复
- 桌面端与手机尺寸自适应

## 数据安全

完整账本存放在浏览器中。清理浏览器数据、切换浏览器或重装系统前，请在“设置”中导出备份文件。建议每周或每月备份一次。

只有主动点击“自动填写”时，本次输入的文字、现有账户名称和当天日期会发送给智谱 AI；历史账目、账户余额和预算不会发送。若不配置 API Key，其余本地记账功能仍可正常使用。
