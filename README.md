# 小账本

一款只在本机使用的个人记账程序。账目默认保存在当前浏览器的本地存储中，不需要账号，也不会上传到服务器。

## 使用方法

首次使用需要安装 Node.js 22 或更高版本，然后在项目目录运行：

```powershell
npm install
npm run dev
```

开发时浏览器打开 `http://localhost:3000`。日常使用直接双击桌面上的“小账本”快捷方式：隐藏启动器会拉起一个极轻的本地服务，并由系统默认浏览器打开 `http://localhost:32145`；关闭页面后服务会自动退出。

小账本不会注册开机启动项。只有双击快捷方式后才会运行；关闭最后一个小账本页面后，本地服务会在约 4 秒内退出。

## 已有功能

- 记录收入和支出，支持编辑、删除、搜索和筛选
- 现金、银行卡、电子钱包等多账户余额
- 月度预算、近七日趋势、支出分类排行和月度结余
- JSON 数据备份与恢复
- 桌面端与手机尺寸自适应

## 数据安全

数据存放在浏览器中。清理浏览器数据、切换浏览器或重装系统前，请在“设置”中导出备份文件。建议每周或每月备份一次。
